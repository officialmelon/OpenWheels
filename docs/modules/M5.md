## Ground facts (verified)
* Itanium layout: derived fields start at the base's *dsize* (aligned to the member), so
  `TargetActionBase::_targetActionType` sits at 0x94 inside LevelItem's tail padding (LevelItem
  dsize 0x94, sizeof 0x98) and LevelItemsDrawNode's first Color4F sits at 0x45c (DrawNode dsize
  0x45c, align 16). libc++ std::function is 0x30 bytes, align 16 (buffer 32 + __f_ at +0x20).
* "static?" in `owre.py methods` is unreliable. Clang DeadArgElim passes `undef` for an unused
  `this` to callers *in the same TU* (e.g. LevelItem::split from createFixture); cross-TU callers
  still do `mov x0,x19`. Rule used: static only if a cross-TU caller does not set x0
  (LevelItem::setTimeStep from LevelB2D; BurstEmitter/FlowEmitter create*; Session/StageCamera/
  FFDrawNode/LevelItemsDrawNode create; FFHelper).
* A 4-byte function that is a lone `ret` returns nothing (`void`), unless callers use x0 (then it
  returns `this`: Session::getGameplayContainer -> Node*). LevelItem::debugFunction is void.
* LevelItem trivial virtuals (init(), die(), paint(), frameAction(), timeStepChanged(),
  getJointBody, removeSprites, getFluidType, shapeImpale, explodeShape, begin/endContact,
  pre/postSolve, jointWillBeDestroyed, bodyWillBeDestroyed, paintWithOffsetPoints, setOpacity,
  prepareForTrigger, getBodyList, debugFunction, actions, singleAction) are linkonce copies in
  other TUs => defined inline in LevelItem.h (done). stopInteractivity, trigger*Activation,
  get/setSpecialType, contactSoundHandler, fixtureWillBeDestroyed, handleContactAdds are in
  LevelItem.cpp (0x5dcd54..0x5de6ac).
* LevelItem statics (.data 0xabb62c..): s_timeStep=1/60 (0x3c888889),
  s_timeStepOverFlashTimeStep=0.5, s_previousTimeStep=1/60, s_timeStepInverse=60, s_flashPtmRatio=62.5.
  setTimeStep: prev=step; step=t; inverse=1/t; overFlash=t/0.033333335f.
* Session has its own *file-static* step at 0xabb640 (no symbol, 1/60). Session::setTimeStep
  writes it then LevelB2D::setTimeStep (each item's timeStepChanged(), then LevelItem::setTimeStep).
  Session::getTimeStep returns it (non-static; callers pass the session).

* LevelItemTextureId: 0 level_items/level_items.plist, 1 level_items/mineExplosion.plist (function-
  local static std::string[2] with guard + atexit).

## ContactListener / DestructionListener
* Listener {fixture, levelItem, std::function<void()> callback} 0x40; callback never set/called but
  copied (loops copy `Listener l = vec[i]`; addToVector reuses one `l` and pushes it, so the
  pushed callback is a copy of the last element's). Dispatch: listener.fixture == fixtureA ->
  item->X(fixtureA, fixtureB, contact) else == fixtureB -> item->X(fixtureB, fixtureA, contact).

  SayGoodbye(b2Body*) is non-virtual (never called by Box2D).

## Phase I facts (implementation)
* Parity noise seen everywhere: FUN_00a322f0 = unwind landing pads (we build -fno-exceptions);
  FUN_00572a20 = __clang_call_terminate (noexcept dtors); FUN_0057587c/FUN_005708bc/FUN_00575a90/
  FUN_005a1f54-style "vector" helpers = libc++ __throw_length_error/bad_array_new_length (newer
  libc++ names them); D0/D1/D2 dtors share one demangled name, so parity pairs them oddly.
* FP contraction: the original is clang -ffp-contract=on (fma only within one expression).
  StageCamera::center's shake offset is a separate statement (fmul+fadd, no fma) while
  CCRANDOM_MINUS1_1() itself is one fma. Check hot math with llvm-objdump vs `owre.py fn --asm`.
* StageCamera: setBorders eases with fminf on increase; decreases of right/bottom borders (and
  left in the fast cases) are unclamped. center(): x/y limits, shake = CCRANDOM_MINUS1_1() *
  halfRange * amount, amount -= 1/60 (fmaxf 0); _midScreen uses the unshaken position.
  The "system_trigger" lambda (@00633f7c) = handleSystemTrigger(event->getUserData()).
* LevelItemsDrawNode: create = plain new + value-init + inlined init(float) (DrawNode::init,
  thickness = ptm*0.02f, setLineWidth). Ligaments/spinal cords: red segment per distance joint
  (GetBodyX()->GetWorldPoint(GetLocalAnchorX())); harpoon ropes: virtual GetAnchorA/B fetched
  twice each (x and y), joints[0] read unconditionally; removeAll leaves spinal cords and
  wrecking-ball delegates.
* ContactListener: int index loops re-reading size(); fixtures A/B read once; whole Listener
  copied per element; addToVector copy-assigns every element into one Listener then pushes it.
  removeFromVector erases every match via iterator.
* DestructionListener: unsigned index loops; erase keeps the index; addFixtureListener uses int
  index; SayGoodbye calls item->X(ptr) before the erase.
* TargetRaycast::ReportFixture: skips sensors; if fraction < _closestFraction records the hit when
  body == target or (density >= 10 or static body) and maskBits & 8; always returns 1.0f.
  Callers (ArrowGun/HarpoonGun) must set _closestFraction = 1 and _targetBody; _hitBody is never
  initialised by them. QueryCallback's code lives in HomingMine's TU (only ReportFixture defined).
* Trigger: begin/endContact act on the other fixture. addTriggeringBody ignores a body that
  already has manifold points with the sensor; endContact decrements _triggeringCount before the
  mass test. setDisabled(false) re-applies the unchanged filter + Refilter(). activateByTrigger
  repeat type 4 sets _triggeringBody = level body (actions() keeps repeating); repeat type 1
  no-delay path calls removeBeginContact(_sensor) without null check. actions() writes
  `*it = elapsedReadBefore + step`. singleAction loop index is a 32-bit unsigned.
  addTriggeringBody calls getSession() and ignores it (RE-NOTE). Sound path: soundFileName(_soundId)
  then static playSound(name, _volume, 1.0f, _panning) or createPositionSound(name, Vec2(x,y), 1, false).
* TargetActionTrigger: create = plain `new TargetActionTrigger()` (zero fill), no null check, init
  result ignored; initWithRefSprite inlined. singleAction casts _receivingTrigger to Trigger*.
* LevelItem: createBody sets type 2, angularDamping 1.0f, allowSleep false, position =
  position + PointFromString("pos"). createFixture(3-arg): friction 0.3f, restitution 0.1f,
  density 1. 5-arg: "size" values are passed to SetAsBox(w, h, center, angle) as half-extents
  (no halving), center defaults b2Vec2_zero; "verts" fills b2Vec2[8] (unsigned loop, no bounds
  check); null if no key. createJoint: enableLimit, maxMotorTorque 4.0f, angle difference read
  before Initialize(); deg->rad (0.0174532924f) rounded before the subtraction (separate
  statements, no fnmsub). contactSoundHandler: returns if other body mass != 0 and lighter;
  rel vel = other - this (GetLinearVelocityFromLocalPoint(manifold localPoint)), max by
  LengthSquared, speed = fabsf(b2Dot(localNormal, v)) > 4 buffers. fixtureWillBeDestroyed only
  erases from _contactAddBufferDict. LevelItem parity: 58/68, rest libc++/landing-pad noise,
  createBodySound inlined into handleContactAdds in our build.
* ReplayData::addEntry writes getData()[_byteIndex] (entry 18001 overwrites _completed, RE-NOTE);
  reset() memsets 18001 bytes (clears _completed) and does not reset _replayIndex.
* FFHelper::isTablet: all float math, roundf on the diagonal.
* TargetAction: RefSprite path never sets _action (singleAction always case 0 = wake); neither
  path sets _targetActionType (stays 0). Case 2 (make dynamic) on the level body builds a new
  dynamic body (old density, friction 0.2f, restitution 0.1f, filter by level version > 1.84f).
  Case 4 (impulse) calls convertRotationData only if props[2] != 0. Case 7 calls
  updateTargetActionsFor even if _shape is null. Fade (TargetAction 3 / Group 1): target =
  props[0]*0.01f, clamp std::fmin(std::fmax(x,0),1); TargetAction resets counter and returns,
  Group resets but doesn't return. Group with null _groupItem removes itself; Group case 2 always
  converts rotation, case 3 no null check. Opacity via virtual GroupItem::getArtOpacity (+0x10).

  convertLengthData; motor ramp unconverted; finish sets _counter = duration (sic). Rev
  SetLimits(props[0], props[1]) * 0.017453292f then convertRotationData; ramp converts props[0]
