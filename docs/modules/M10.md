## Audio (SoundController / Sound / SoundList)
* API: `cocos2d::experimental::AudioEngine` only (play2d, setVolume, setLoop, setFinishCallback,
  stop, pause, pauseAll, resumeAll, getState, preload). Effects ".ogg", music ".mp3".
* SoundController ctor order: `_paused=false; _sounds={}; _position=0; _masterVolume=0; _musicId=-1;
  _areaSoundPitch=1.0f; v=UserDefault "sound_volume_offset"; _paused=false;
  _masterVolume=(float)(v+100)/100.0 (check float vs double); _soundList=new SoundList()`.
  init() repeats the body (and leaks the previous SoundList); unused.
* playSound(name, a, b, c) is STATIC and ignores a/b/c: `return Sound::playSound(name, 1, 1, 0, false)`.
* playBackgroundMusic(name): if masterVolume == 0 or musicId != -1 return -1; empty name ->
  name.assign("SuperPretzel") (modifies the by-value param); id = play2d(name + ".mp3", false, 1.0f);
  _musicId = id; setVolume(id, master * limiter); return _musicId.
* stopBackgroundMusic: if (_musicId != -1) AudioEngine::stop(_musicId) - does NOT reset _musicId
  (so music can never restart in the same process) - verified with the asm in Phase I.
* createBodySound / createPositionSound: `if (_sounds.size() < 24) { s = new (std::nothrow) Sound();
  if (s->init(name, body|nullptr, pos|(0,0), _position, 1.0f, _masterVolume, true, loop, pitch,
  _areaSoundPitch) && _sounds.size() < 24) push_back, return s; else delete s; } return nullptr`
  (the size check is repeated inside the inlined push; delete path = inlined ~Sound). Note the
  nothrow-new result is NOT null-checked before init.
* update(listener): `if (!_paused) { _position = listener; for (it...) if (!s->updatePosition(l.x, l.y,
  _masterVolume)) { s->stop(); s->triggerCallback(); erase(it); delete s; } else ++it; }`.
* stopAllSounds(remove): stop() all (index loop); if remove: same reap loop as update but
  unconditional, then end = begin.
* setMasterVolume: v = fminnm(v, 1.0f); if (v <= 0) v = 0; store; if musicId != -1 setVolume(musicId,
  v * limiter). Made static (only touches statics; getMasterVolume must be static because the static
  Sound::playSound calls it without an object).
* Sound::init: empty name -> false. Clears _finishedPlaying, resets _finishCallback (= nullptr),
  _soundId=-1, _fileName=name, _maxVolume=maxVolume, _defaultPitch=defaultPitch, body ? position =
  body->GetPosition(); _body=body; _soundPosition=pos; _looping=loop; if (!playImmediately)
  AudioEngine::preload(getFullPath(name,"ogg")) else if (!play(1.0f, false)) return false;
  updatePosition(listener.x, listener.y, masterVolume); return true. (masterPitch unused.)
* Sound::play: if _soundId == -1: id = play2d(path, loop, volume); if id != -1 { if (_looping)
  setLoop(id, true); setFinishCallback(id, [this](int, const std::string&){ soundFinishedPlaying(); }) }
  return id != -1; else return true.
* updatePosition: id == -1 -> true. finished -> false. Fade step (as updateFade, inlined). body ->
  _soundPosition = body->GetPosition(). |dx| > 16 || |dy| > 8 -> setVolume(0), return _looping.
  else setVolume(fminnm((|dx| * -0.0625f + 1) * maxV, (|dy| * -0.125f + 1) * maxV) * master); true.
* fadeTo(target, duration, stop): if (target != _targetVolume || stop != _stopOnComplete) { if
  (_maxVolume == target) { if (stop) stop(); } else { _targetVolume = target; _stopOnComplete = stop;
  _steps = (int)(duration / 0.016666668f); _volumeIncrement = (target - _maxVolume) /
  (float)(unsigned)(int)(float)(int)(duration / 0.016666668f) } } (ucvtf - check exact casts).
* SoundList ctor (Phase I): read "soundlist.tsv" via FileUtils::getStringFromFile, per line
  `id \t name \t file`: _sfxArray.push_back(name); _sfxDictionary[name] = file. _sfxLookup stays empty.
  soundFileNameForId prints `name << " : " << file << std::endl` to std::cout (keep).

## Ads (AdController) - PC stub plan
Original: banner/interstitial/rewarded via JNI AdHelper (AppLovin MAX). Gameplay calls showAd(Banner)
when pausing/dying/victory (no effect when ads removed), showAd(Interstitial) in
oneFrameAfterOnEnterTransitionDidFinish: true -> waits for interstitialDidEnd; false -> delegate
cleared and beginGameplayFollowingInterstitial() immediately. Mascot uses showAd(RewardedVideo)
and waits for rewardedVideoDidUpdateStatus.
PC: no JNI; showAd returns false for every type and starts nothing ("not available"), so gameplay
starts at once. For RewardedVideo the Java helper would report status 0/4 when unavailable; decide in
Phase I whether to call `_delegate->rewardedVideoDidUpdateStatus(RewardedVideoStatusFailed)` so the
Mascot UI does not wait forever (check Mascot @005ebb54 / caller @Mascot.c:1483). Keep timer logic
(startGameplayTimer/update/resetElapsedTime) faithful. JNI entry points: not compiled on PC.
Note original quirk: with ads removed, showAd(Interstitial) calls delegate->interstitialDidEnd(2)
synchronously AND returns false -> Gameplay begins twice (now + after 0.25 s). PC stub avoids it.

## Selected level "file path" (+0x150) - answer
`_selectedLevelFilePath` is set to "" by the Settings ctor and never changed (setSelectedLevelFilePath
has no callers). Gameplay::init(std::string) uses getSelectedLevelFilePath() when its argument is
empty, CharacterSelectLayer passes it to Gameplay::createScene, Session::setupLevel(str, bool) passes
it unchanged to LevelB2D::init(str), and LevelB2D::init replaces an empty string with
Settings::getLevelXMLData() = contents of "levels/" + levelData["dataFile"] (read with
FileUtils::getStringFromFile by updateLevelDataFromFile into `_levelXMLData` +0x80). The string given
to LevelXMLParser::init is therefore always XML text. DebugScene::createEmitterTest passes
"levels/debug/debug.xml" (a path) to setupLevel - in 1.1.3 that would be parsed as XML (dead code).
