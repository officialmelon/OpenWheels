Status: Phase H done (18 verified headers); Phase I done (all .cpp written, compiled, parity-checked,
LevelB2D shape/group loading validated against the oracle for 65 levels). See "Phase I status" at the end.
Addresses are Ghidra addresses. Decomp: `reports/decomp/classes/<Class>.c`.

## Class layouts (arm64)

### LevelXMLParser (no vtable, sizeof 8)
- +0x00 `LevelXMLParserDelegateProtocol* _delegate` (only set by init when xml non-empty).
- Created in `LevelB2D::init` as `new LevelXMLParser()` (8 bytes, zeroed), `init(xml, this)`, `delete`.

### LevelXMLParserDelegateProtocol (pure interface, no virtual dtor)
vtable order (from LevelB2D primary vtable): addInfo(LevelDataElement*), addSpecial(LevelDataElement*,int),
addShape(LevelDataElement*,int), addGroup(LevelDataElement*,int), addJoint(LevelDataElement*,int),
addTrigger(LevelDataElement*,int), addTriggersComplete(). LevelB2D's own D1/D0 come right after
(slots 7/8) => protocol has no virtual destructor (or declared it last). We declare none.

### ShapeItemDelegate (pure interface)
vtable: [~ShapeItemDelegate D1, D0, removeShapeItem(ShapeItem*, bool)] (LevelB2D secondary table @+8).

### LevelB2D::update(float dt) @005cdc58
1. sizes of _groupItems AND _foregroundGroupItems are read before either loop (load order in asm).
   if ((int)fg.size() > 0) for g in fg: g->update(); if ((int)bg.size() > 0) for g in bg: g->update().
2. for item in _singleActionVector: item->singleAction(); _singleActionVector.clear().
3. for item in _actionsVector: item->actions().
4. if (_frameActionTimer >= 0.016666668f) { for item in _frameActions: frameAction(); timer = 0 }; timer += dt.
5. for a in _actionsToAdd: if not in _actionsVector → push_back; clear.
6. for a in _actionsToRemove: erase first match from _actionsVector; clear.
7. for a in _frameActionsToRemove: erase from _frameActions; clear.

### LevelB2D::paint() @005ce02c
for body in _paintBodies: node = (Node*)body->GetUserData(); node->setPosition(Vec2(p.x*ptm, p.y*ptm));
node->setRotation(body->GetAngle() * -57.29578f /* CC_RADIANS_TO_DEGREES negated */). Then paintItems: paint().

- convertDirectionIfNecessaryBasedOnRegistration(f): if (_registration) *f = -*f.

### addShape(e, group, groupOffset, index, foreground) @005d0cb4 → ShapeItem*
Shape "t": 0 rectangle, 1 circle, 2 triangle, 3 polygon (verts cache _polygonVerts by <v id>),
4 art polygon (cache _artVerts), 5 terrain (cache _terrainVerts; b2ChainShape loop on the level body,
art into Session::getTerrainNode(), TerrainShape item). Attributes: i interactive (default t),

add segments-1 bezier points (calculateBezier inlined, t = j/segments); then drop consecutive points with
dist² < 2.5e-05f; CreateLoop; art verts * _ptmRatio; TerrainNode::drawPolyWithVerts(verts, n, fill,
borderWidth 0, Color4F(0,0,0,0)).
