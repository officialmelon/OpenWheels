## Level loading chain (answer to "<game text>")
The menus never read the file. LevelSelectMenu::levelBtnPressed -> Settings::setSelectedLevel(ch, lv)
(M10, @006105e8) -> Settings::updateLevelDataFromFile() (@00610654): getLevelData(...)["dataFile"],
FileUtils::getStringFromFile("levels/" + dataFile) -> Settings+0x80 (XML contents). Then the menu
calls Gameplay::createScene(std::string(""), nullptr) (or CharacterSelectLayer::createScene(0, ..)
when the chapter's "characterIndex" is -1; CharacterSelectLayer::handleConfirmButtonReleased then
calls Gameplay::createScene(Settings::getSelectedLevelFilePath(), nullptr)). Gameplay::init: empty
string -> Settings::getSelectedLevelFilePath() (Settings+0x150, normally empty).
