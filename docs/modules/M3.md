## Cross-cutting facts for Phase I
* `create()` of all four classes and RoadBike's **ctor** were **inline in the original headers**:
  their copies are emitted in the caller TUs (Moped::create @005f4320 in MopedCouple's,
  MotorCart::create @005acd38 in EffectiveShopper's, PogoStick::create @00608774 in PogostickGuy's,
  RoadBike::create @005cb794 + RoadBike() @005cbc08 in IrresponsibleDad's). Define them in the headers.
* create(): verified for all four: `operator new(N, nothrow)` with **no memset** → user-provided
  ctors, no zero-fill (coordinator rule: memset ⇒ value-init `X()`, none ⇒ user ctor). Then
  `init(position, name, groupID)` (virtual); false → `delete` (vtable +8), else autorelease.
  Uninitialised members therefore stay indeterminate (documented per field in the headers).
* MotorCart::createBodies and RoadBike::createBodies call `patch::to_string<unsigned int>` (dict
  keys built from an index) → `#include "Patch.h"` (shared, ostringstream-based like the original).
* Callers outside M3: MopedCouple → Moped::create/addDriver/addPassenger; IrresponsibleDad →
  RoadBike::create/addDad/addKid; EffectiveShopper → MotorCart::create; PogostickGuy → PogoStick::create.
* Ctor quirks: MotorCart and RoadBike ctors explicitly null Vehicle's `_frontWheelFixture`/
  `_backWheelFixture` (Moped/PogoStick ctors don't → Vehicle must not NSDMI them; reported to M2).
  RoadBike ctor: `_seatChest = _seatPelvis = _seatUpperLeg1 = _seatUpperLeg2;` (reads the
  uninitialised last one; stores 0x240, 0x238, 0x230), constructs `_embeddedSprite` mid-way.
  PogoStick ctor: every b2Vec2 member = `b2Vec2_zero`, joint defs default-constructed.
* `_INIT_17` @00608358 = static initialisers of PogoStick.cpp: 0xac6518..0xac6533 are cocos2d's
  PHYSICS*_MATERIAL_DEFAULT (every TU); 0xac6534 = `(30.0f / globals::flash::ptmRatio) * 0.5f`
  (s_hopTranslation), 0xac6538 = `(40.0f / ptmRatio) * 0.5f` (s_chargeTranslation) — FLOAT math.
* Several helpers have no direct callers (inlined at call sites): Moped::stopEngineSound (die,
  frameSmash), PogoStick::nubContactAdd/Remove (begin/endContact), getCenterOfMass, ... still write them.
* `Vehicle::addBodyVehicleJoint` is called virtually (vptr+0x1c0) by RoadBike::addDad/addKid, but
  Moped::attachCharacter inlines `_bodyVehicleJointDict[body] = joint` directly.

## Phase I findings (behaviour facts)
### Common
* All vehicles: `postSolve` impulse = n[0], or `b2Max(n[0], n[1])` when pointCount == 2. Smash
  functions mostly ignore their impulse argument; handleContactResults still does the extra map
  lookups for the arguments (kept).
* Lean impulses differ per class: PogoStick uses `_impulseOffset` along local y and a float
  (cos, sin) direction; RoadBike uses `_impulseOffset` along local x with a double
  sin/cos(angle + pi) direction (impulse = (s, -c)·k); Moped/MotorCart use a literal ±1 offset.
* Clamp idioms: fmaxnm/fminnm ⇒ `b2Min(b2Max(x,0),1)`, fminnm+fcsel ⇒ `b2Clamp`; some lean factors
  are clamped in double (RoadBike/Moped/MotorCart leanBack).
### PogoStick
* Bodies: frame box then rod box (density 5, friction 1, restitution 0.1, `_defaultFilter`), nub
  circle r 0.056 at (0, -rod half height) restitution 0.3; bodyDef angle = plist "rot" (radians).
* Prismatic frame↔rod: axis (-sin a, cos a), limits 0/0 enabled, motor enabled, force 10000.
* addCharacter: limits relative to current angles (hip 0..100°, shoulder 0..120°, elbow 0..60°,
  neck -5°..0); hands to "handleAnchor" (limits -10°..100°), feet to "footAnchor" (±10°); COM
  array = frame, rod, head, chest, pelvis, arms, legs; `_prevCOM` initialised.
* frameSmash removes the frame from LevelItem's `_contactResultBufferDict`; brokenframe sprites
  only exist in SessionModeGameplay (crash otherwise, as in the original).
### RoadBike
* createBodies: wheels/gear circles (density 5, friction 1, restitution 0.3, category 0x201),
  bodyDef angularDamping 1, allowSleep false; frame (density 2, friction 0.3, rest 0.1) fixtures
  frame (0x201) / fork (_zeroFilter) / seat (0x201) via LevelItem::createFixture; separate seat
  body with "seat1".."seat3" (seat3 sensor), filter {default cat/mask, group -2}. Verified vs the
  oracle dump of 02_irresponsible_dad_01.
* Joints: front wheel, back wheel (maxMotorTorque 20), frame-gear, gear joint (bodyA back wheel,
  bodyB gear, ratio -1), seat joint (limit 0/0). Dad joints maxMotorTorque 20, no limits.
* backWheelSmash measures the normal angle against the FRONT wheel body (bug kept).
* frameSmash: parts seat/fork/broken from "bodies"/{seat,fork,broken} with the frame's first
  fixture material + _zeroFilter, frame velocity copied; sound "BikeSmash1"; removeFromActions.
### Moped
* createBodies fixtures: density 3, friction 0.3, restitution 0.1, `_zeroFilter`, order engine,
  middle, rear, back wheel body, front wheel body, fork, tank, seat. Engine loop "MopedLoop2" is
  attached to the FRONT wheel body. `random()` tail-calls frameSmash; handleFramePostSolve has no callers.
* frameSmash: 6 parts (fork, seat, middle, engine, rear, tank) with the fork fixture's material;
  sound "MetalSmashMedium". Wheel smash sprites `_frontWheel_Broken.png` / `_backWheel_broken.png`
  (case differs, kept). frameAction's non-boost branch resets `_targetPitch` to 1 after use.
### MotorCart
* createBodies stores the shaft fixture into `_mainFixture4` (overwriting rear); `_shaftFixture`
  stays null. Frame density 4 / friction 0.3 / rest 0.1 / filter {0x201, 0xffff, -2}; wheels and
  shocks density 5 / friction 1 / rest 0.3; groceries boxes zero filter, density 0.25.
* Joints: prismatic frame↔back then front shock (axis (0,1), limits 0/0, force 1000), revolute
  shock↔wheel (torque `_maxTorque`); addWheelJoint front first. Verified vs 04_effective_shopper_01.
* ejectCharacter returns the pre-eject `!_ejected`; debugFunction → frameSmash (args undefined).
