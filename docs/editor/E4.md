# E4 — editor UI (Phase H + I notes)

Owner: E4. Code in `src/editor/ui/` (headers + .cpp, every iOS method tagged `// @ios <addr>`).
Ground truth: `iosre.py fn <Class>`; the compiled nibs in the player's iOS bundle. Scratch tools
(not committed): `build/tmp/e4/nibdump.py` (NIBArchive dumper), `niblayout.py` (view tree + frames +
outlets), `nibcons.py` (autolayout constraints), `iosdis.py <start> <end>` (capstone arm64
disassembly of the iOS binary with cfstring / selector / class / ivar annotations — used for the
methods missing from the Ghidra export and wherever Ghidra's float code was unreliable).

UIKit mapping: UILabel → `ui::Text` (`uikit::makeLabel`); UIButton → `ui::Button`, scale-9 of the
bundle's loose `<prefix>Button@2x.png` / `…ButtonHighlight@2x.png` (72×72 px, 4 pt caps;
`uikit::skinButton`); UISlider → `uikit::Slider` and UISwitch → `uikit::Switch` (drawn with DrawNode —
system controls have no iOS art; the slider only tracks drags that start on the thumb, like UISlider,
whereas cocos' `ui::Slider` jumps on track taps); UITextField → `ui::EditBox` (right-aligned, value
committed only when editing ends with Return, like `textFieldShouldReturn:`); UITableView /
UIPickerView → `ui::ListView`; UIAlertView → `HWWindow` via E5's `levelui::showAlert` (z above
`uikit::window()`). Fonts: Helvetica-Bold / system → Arial Bold / Arial TTF (`uikit::fontFile`),
system-font fallback. Most loose bundle PNGs (the `*_cellIcon.png`) are Apple **CgBI** PNGs (raw
deflate, BGRA, premultiplied); `uikit::imageNamed` decodes them with zlib.

Geometry: all iOS frames are kept in **points, top-left origin**; `uikit::View` flips them into cocos
coordinates, scale `EditorAssets::pointsToDesign()`; `uikit::windowSize()` = visible design size /
pointsToDesign (≈1382×768 at 3600×2000). Panels go into `uikit::window()` (full-screen View above the
running scene, z 100000, touch-transparent) — the stand-in for `[CCDirector sharedDirector].view`.
Notifications: `uikit::NotificationCenter` (EventCustom, userData = object; observers grouped by owner).

## InputObject contract (E1/E2 → E4)

```cpp
InputObject*       InputObject::create(const cocos2d::Rect& frame, const std::string& label,
                       const std::string& property, float initialValue, bool addDisplayValueTextField);
SliderInputObject* SliderInputObject::create(const cocos2d::Rect& frame, const std::string& label,
                       const std::string& property, float initialValue, float minValue, float maxValue,
                       unsigned int segments);
SwitchInputObject* SwitchInputObject::create(const cocos2d::Rect& frame, const std::string& label,
                       const std::string& property, float initialValue);
ColorInputObject*  ColorInputObject::create(const cocos2d::Rect& frame, const std::string& label,
                       const std::string& colorLabel, const std::string& property, float initialValue,
                       float minValue, float maxValue, unsigned int segments);
void InputObject::setMinValue(float minValue, float maxValue);   // enables limits
void InputObject::setIsAngleValue(bool);
```

* All static, autoreleased; odd values (e.g. a huge unsigned `segments` from a negative `max - min`)
  never crash: float→int conversions use saturating `uikit::fcvtzs/fcvtzu` (arm64 semantics).
* `frame`: iPad points relative to the inspector's scroll content, top-left origin
  (EditParametersView passes `(8, y, scrollW - 16, 27)`); kept as `frame()`; rows stack by
  `frame().size.height + 8`.
* `label` / `colorLabel`: Localizable.strings key (e.g. `"ANGLE"`); displayed as
  `lowercase(Localization::get(label) + ":")` (falls back to the literal, so `"r"` and
  already-localized text work). Empty = nil (no label).
* `property`: the Special KVC key. Special's `inputObjectForPropertyWithRect(key, rect)` returns
  the row or nullptr.
* Row heights: InputObject / SwitchInputObject keep the frame (27); SliderInputObject is
  `2·(int)h + 4` (slider line at `(int)h + 4`); ColorInputObject is `(int)h + 4`, or `2·(int)h + 4`
  with a caption label.
* Slider snapping uses **roundf** (`frinta`; Ghidra prints an int cast); ColorInputObject first
  rounds to 1/100. SliderInputObject.showDecimal is cleared when `fmodf(max - min, segments) == 0`,
  ColorInputObject's when it is `!= 0` (both from the assembly).
* Value semantics and undo flags: see `InputObject.h` (setPropertyValue range check, Return →
  clamp / 360° wrap, slider began/change/end, switch → 0/1, delegate
  `inputObjectParameter(parameter, value, updateUndo, previousValue)` with `Value::Null` = nil).

## Screens

* **EditorUIView** — base panel: scroll view (8, 8, w−16, trunc(h−54)), title label, pink "CLOSE"
  button → posts `editor_view_closed` (object = panel); EditorLayer::hideMenu: removes it.
* **AddSpecialItemUIView** — "ADD ITEMS": sectioned list from `EditorSettings` (18 pt section
  headers, icons `<Key>_cellIcon.png`); select → posts `editor_view_item_added` (`int*` id) → closes;
  the scroll offset is kept in `EditorSettings::scrollViewYOffset`.
* **SelectBackgroundUIView** — picker (NONE, GREEN HILLS, CLOUDS, HONEYCOMB, BRICKS, SOLID COLOR) →
  `delegate->editorUIView(this, bg, "bg", {})`; solid colour adds r/g/b ColorInputObjects
  (4, 36/69/102, scrollW−8, 30); close sends `"bgColor"` = 0xRRGGBB. Row↔value table in the header.
* **EditParametersView** — single selection only (2+ → "MULTIPLE OBJECTS", 0 → "NOTHING SELECTED");
  UI→model with undo grouping (`prepareWithInvocationTarget` → `setValueForKey(old, key)`),
  model→UI via Special observers; "angle" label tap: `fmodf(r,45)==0 ? fmodf(r+45,360) :
  ceilf(r·(1/45))·45`. Posts `undo_stack_updated`, `sel_rect_changed`.
* **AlignRefsView** — "ALIGN OBJECTS": up/down/left/right align to the union of `refBoundingBox()`
  (doubles, union kept in float like iOS), then `sbn->updateSelectionRect()`; no undo (iOS).
* **EditorMenuViewController** — main menu: Save (E5 SaveLevelViewController, current-context
  presentation, observes `save_level_cancel` / `save_level_done` with the VC as object), Load
  (lose-changes alert type 2 → `confirmLoadLevel` presents LoadLevelViewController), New (alert 0 →
  `LevelSession::clearLevelData` + `editorLayer->newLevel()`, dismiss popover), Main menu (alert 1 →
  dismiss + `MainMenu::createScene(MenuModeMain)`), Share (`ShareAction::shareLevelDataFile` = export
  to file), Lock / Unlock, Center to character, rotate-independently / paste-in-place switches,
  Close → posts `main_menu_closed`.

Layout recovery: programmatic panels from `initWithFrame:` code (verified in the assembly).
EditorMenuViewController from `EditorMenuViewController.nib/objects-11.0+.nib` (NIBArchive): outlets,
actions and constraints, resolved for the 480×320 popover: container (0, 0, 475, 260) grey 0.8 on a
0.706 root; left column x 9 (save 8, new 56, load 104, share 152, main menu 201/h 38); right column
x 303 (lock 8, unlock 56, centre 200), switches x 404 (y 108, 152), switch labels x 321 (y 108, 151);
name label (10, 280, 242, 21) bold 17 white; close (320, 271, 160, 39). Snap-rotation controls are
outside the view hierarchy (invisible on iOS; kept invisible). The 13 methods missing from the
export were read from the arm64 code; skinButton:style: jump table: 1 blue, 2 yellow (black title),
3 grey, 4 darkGrey, else pink. lockBtn enabled iff 2+ selected refs or exactly one non-CharacterRef;
unlockBtn iff lockedRefs is non-empty ("UNLOCK n ITEMS", else "UNLOCK ALL").

Localization keys used by E4: CLOSE, ADD ITEMS, SELECT BACKGROUND, NONE, GREEN HILLS, CLOUDS,
HONEYCOMB, BRICKS, SOLID COLOR, ALIGN OBJECTS, OK, NOTHING SELECTED, MULTIPLE OBJECTS, EDITOR MENU,
SAVE LEVEL, LOAD LEVEL, SHARE LEVEL, NEW LEVEL, MAIN MENU, CLOSE MENU, LOCK SELECTION, UNLOCK, ITEMS,
UNLOCK ALL, CENTER TO CHARACTER, "ROTATE ITEMS\nSEPARATELY", "SNAP TO\nANGLE", "PASTE IN\nPLACE", plus
the catalog's section/item keys. iOS hard-codes "Hey" / "Lose changes?" / "Yes" / "No" and
"up/down/left/right": short literals through `Localization::get` (literal fallback).

## Phase I decisions / deviations

* Editor menu = iPad popover (`EditorPopoverController`: content size 480×320, placed next to the
  anchor rect; tap outside → `shouldDismissPopover` / `didDismissPopover` callbacks for EditorLayer).
  `presentViewController` honours UIModalPresentationCurrentContext (3): Save/Load cover the popover.
* `saveLevelCancel:` / `saveLevelDone:` send the KVO selector `removeObserver:forKeyPath:` to the
  notification centre on iOS; the port removes the two notification observers.
* AddSpecialItemUIView: iOS cells keep the icons' natural size (85–170 px); the port fits them in a
  50 pt box in 60 pt rows (RE-TODO in the source).
* EditParametersView keyboard methods are kept but inert (no software keyboard on PC);
  `scrollToKeyboardFocus` is approximate (RE-TODO).
* AlignRefsView's OK button lies outside its scroll view's bounds on iOS too (clipped) — kept.
* SelectBackgroundUIView keeps the iOS bug that tests gColor twice (blue never checked) when deciding
  whether the initial colour is "white".
* Analytics (`HWTracker`) calls are dropped.

## Interfaces used

* **E1**: `Special::propertyKeysForUI / name / getRotation / setAngle / inputObjectForPropertyWithRect
  / valueForKey / setValueForKey / addObserver / removeObserver / refBoundingBox (cg::Rect)`,
  `CharacterRef`, `EditorSettings` (catalog).
* **E3**: EditorLayer (implements `EditorUIViewLayerDelegate::editorUIView(view, value, key, const
  ValueMap& userInfo)`, empty map = nil; `unsavedChanges, newLevel, lockSelection, unlockAll,
  lockedRefs, selectedRefs, rotateItemsIndependently/set…, snapToAngle, pasteInPlace/setPasteInPlace,
  centerToCharacter, levelData, characterIndex, forceCharacter, levelMO`); `EditorSpriteBatchNode::
  updateSelectionRect`; `EditorUndoManager::begin/endUndoGrouping, prepareWithInvocationTarget`.
  E3 presents the menu: `EditorPopoverController::create(menu)`, `setPopoverContentSize({480,320})`,
  `presentPopoverFromRect(menuButtonRect, …)`, `menu->setPopoverController(popover)`.
* **E5**: `SaveLevelViewController::create(levelMO)` + `setEditorLayer`, `LoadLevelViewController::
  create()`, `ShareAction::shareLevelDataFile`, `LevelSession::clearLevelData`,
  `levelui::showAlert / buttonIndex`; E5's view controllers derive from `EditorViewController`,
  `UserLevelSelectUIView` from `EditorUIView`.
