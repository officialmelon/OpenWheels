# E1 — editor model core (`Special`, `RefShape` family, `CharacterRef`, `DecorationRef`)

Owner: editor agent E1. Source: iOS 1.2.7 (`iosre.py fn/ivars`) plus arm64 disassembly of the
Mach-O for what Ghidra drops (varargs key lists, float arguments in s-registers, string
literals). Headers: `src/editor/model/{Special,RefShape,CircleRefShape,RectangleRefShape,
TriangleRefShape,CharacterRef,DecorationRef,EditorSettings}.{h,cpp}`. Phase H (headers) and
Phase I (implementation) done; every iOS selector of the 8 classes is implemented and tagged
`// @ios <addr>`; each `.cpp` passes `tools/check_tu.sh`. Integrated and running in the MSVC
build since the editor port landed (the integration fixes are in that commit).

Classes (bases): `Special : cocos2d::Sprite`; `RefShape : Special`; `Circle/Rectangle/
TriangleRefShape : RefShape`; `CharacterRef : Special`; `DecorationRef : Special`.
Adopted helper: `EditorSettings` — the editor half of iOS `Settings` (item registry:
id → ref class / name / sections; `levelItemRefClass:`, `nameForLevelItem:`,
`keyForLevelItem:`, `sectionedLevelItemIDs`, `sectionNames`, `scrollViewYOffset`). Needed by
`Special::name`, EditorLayer (`addSingleItem`, `pasteInPlace`, `addCharacter`,
`handleMenuTouch`) and AddSpecialItemUIView. No polygon/art ref exists on iOS.

## Conventions agreed with E2

* Construction: `CREATE_FUNC(T)` → `T::create()`; `bool init() override` is iOS `-init`.
  iOS instance `-create` → `virtual void createRef()`.
* `-inputObjectForProperty:withRect:` → `inputObjectForPropertyWithRect(key, rect)`.
* `-setX:y:` → `setX(float, float)` (overload of `setX(const Value&)`).
* Setters whose iOS argument is an `NSNumber*` take `const cocos2d::Value&`
  (`setX/setY/setXMeters/setYMeters/setAngle/setFixed/setSleeping/setInteractive`,
  `setDefaultCharacter`, `setForceCharacter`, `setDecorationType`); scalar setters take scalars.
* ivars whose name equals the accessor (`x y ptmRatio fixed sleeping snaps interactive`,
  Decoration's `decorationType sprite shapeCountDict`) get a leading `_`.
* Geometry (requested by E3): `refRect()`, `setRefRect()`, `refBoundingBox()`, `startPos()`,
  `setStartPos()`, `containsPoint()` use E3's double `cg::Rect` / `cg::Point`
  (`EditorGeometry.h`); `setRefRect(const cocos2d::Rect&)` is kept as a float convenience.
* InputObject labels are Localizable KEYS (E4 localizes; `""` = nil label).
* Notifications go through `uikit::NotificationCenter::postNotification` (E4).
* Art scale: `Special::editorArtScale()` = contentScaleFactor / pixelsPerPoint converts a
  sprite's texture/content size to iPad points and is the `setScale` for child art; refRects
  built from art sizes must be multiplied by it (Special's own `e_1x1` refRect, CharacterRef,
  DecorationRef do). The ref node itself stays at scale 1.
* Draw node for `updateDrawingWithNode`: `cocos2d::DrawNode*` (iOS `CCDrawNode`:
  `drawDot:radius:color:`, `drawPolyWithVerts:count:fillColor:borderWidth:borderColor:`).
  E3 owns the node (`EditorSpriteBatchNode::drawNode`). Calling the default no-op on every ref
  is equivalent to iOS's `respondsToSelector:` check.

## Serialization

* XML (`-[EditorLayer levelData]`, E3): refs[0] is the CharacterRef → `<info v="1.70" (1.7f) x y c f h
  bg bgc e="1" fm="m"/>` (`%.02f` x/y meters, `c` defaultCharacter, `f` forceCharacter, `h`
  hideVehicle). Other refs: `isKindOfClass:RefShape` → `<sh t="%i" i="%i" ` with
  `levelItemID - 6000` and `interactive`; else `<sp t="%i" ` with `levelItemID`. Then per
  propertyKeys[i]: `v = [[ref valueForKey:k] floatValue]`; `fmodf(v, 1) == 0` →
  `p%i="%i" ` with `(int)v`, else `p%i="%.02f" `; then ` />`.
* Copy/paste (`-[Special properties]` @1000b5ad0): `{"t": @(levelItemID), "p<i>": string}`,
  string = `"%.02f"`, and if it contains `".00"` the last 3 chars are dropped. No `"i"`.
* `-[Special setProperties:]` @1000b59e4: logs `"--ref shape set properties: %@"`; if `p0`
  present: for i = 0.. while `p<i>` present: `setValue:@([dict[p<i>] floatValue])
  forKey:propertyKeys[i]` (index past the key list → NSRangeException on iOS).
* RefShape `setProperties:` @1000da5a0: `_interactive = dict["i"] ? boolValue : YES` (ivar
  write, no count update); if `p12` exists it replaces `p11` and is removed (old 13-key
  format); then Special's.
* Load path (E3): `addShape:` → `addSingleItem(t + 6000, dict)`; `addSpecial:` →
  `addSingleItem(t, dict)` → `[[registry class] alloc] init]`, `setProperties:`, `create`,
  `addRef:`.

## KVC / KVO (port mechanism)

`valueForKey`/`setValueForKey` are virtual and chain to the base. Key sets:
Special — x y xMeters yMeters angle fixed sleeping interactive width height;
RefShape — + widthMeters heightMeters density color outlineColor shapeOpacity collision
innerRed innerGreen innerBlue (width/height overridden); CharacterRef — + defaultCharacter
forceCharacter hideVehicle dictIndex; DecorationRef — + decorationType.
NSNumber conversions: `kvcFloat/kvcInt/kvcUnsigned/kvcBool` (truncation; unsigned of a
negative float saturates to 0 as arm64 `fcvtzu`; bool = non-zero). Getter boxing: float →
`Value(float)`, BOOL → `Value(bool)`, int/unsigned → `Value(int)`.

KVO: EditParametersView (E4) calls `ref->addObserver(this, key, cb)` for each
`propertyKeysForUI()` key and `removeObserver(this, key)`; callback gets
`valueForKey(key)`. Every `set<Key>` setter opens `KeyValueChange kvo(this, "<key>")` first;
the outermost scope per key notifies on exit (iOS automatic KVO: once per outermost setter
call, after the override's own code). Setting position/rotation directly (`setPosition`,
`setRotation`) does not notify (as on iOS: only `setX:`/`setY:`/`setAngle:` do).

## Notifications (EventCustom, userData = object)

`SHAPE_COUNT_UPDATE` (nullptr) from `setShapeCount`; `ART_COUNT_UPDATE` (nullptr) from
`setArtCount`; `ref_ui_keys_will_change` / `ref_ui_keys_changed` (object = ref) around
UI-key-list changes (RefShape/DecorationRef `setInteractive`, DecorationRef `setFixed`, E2's).

## Special — behaviour

* `initWithSpriteFrameName:` @1000b4fc8 → super; snaps 1, canDragModify 0, locked 0,
  canRotate 1, interactive 1, ptmRatio = Session ptmRatio. `initWithSpriteFrame:` @1000b50a4
  → super; `_propertyKeys = [xMeters, yMeters, angle, fixed, sleeping]`;
  `refRect.size = textureRect.size` (origin 0,0). All refs init from frame `"e_1x1.png"`.
* `name` = `Settings nameForLevelItem:levelItemID`.
* `onEnter` caches `position` into `_x/_y` then super. `setX:` sets `_x` and
  `setPosition:(_x, _y)` (dynamic → CharacterRef override); `setY:` likewise. `x`/`y`
  getters return `position`, the x/y InputObjects start from the cached `_x/_y`.
* `xMeters = (float)((double)position.x / ptmRatio)`; `setXMeters:` → `setX:@(ptm * v)` (float).
* `setAngle:` → `setRotation:(floatValue)` (dynamic; CharacterRef/E2 no-op overrides).
  `angle` = `rotation`.
* `fixed/sleeping/interactive` setters store `boolValue`. `width/height` = 0, setters no-op.
* `setShapeCount:`/`setArtCount:` store and post notifications.
* `containsPoint:` @1000b559c: `[self convertToNodeSpace:[parent convertToWorldSpace:p]]`,
  `CGRectContainsPoint(refRect)` — half-open on max edges (cocos2d-x Rect::containsPoint is
  closed; implement explicitly).
* `refBoundingBox` = `CGRectApplyAffineTransform(refRect, nodeToParentTransform)`
  (cocos2d-x `RectApplyAffineTransform(r, getNodeToParentAffineTransform())`).
  `_refBoundingBox`/setter exist but are never read.
* `nodeToParentTransformWithPosition:` @1000b5c44: cocos2d-iphone 2.x transform with a given
  position (rotationX/Y, skew, anchor). No callers. Port for completeness.
* `inputObjectForProperty:withRect:` @1000b5154: x/y → `InputObject(frame, X|Y, "x"|"y",
  _x|_y, addDisplayValueTextField YES)`; angle → `InputObject(ANGLE, "angle", rotation, YES)`
  + `setMinValue:0 maxValue:360` + `setIsAngleValue:YES`; fixed/sleeping/interactive →
  `SwitchInputObject(FIXED|SLEEPING|INTERACTIVE, key, flag ? 1 : 0)`; else nil.
* `create`, `update` no-ops. `dealloc` only super.

## RefShape — constants

* init @1000da374: frame "e_1x1.png"; inner r,g,b,opacity from file statics (initial
  61, 136, 199, 100; `0x101bc32e0..ec`), `innerColor = (r,g,b) * 0.003921569f, a = op * 0.01f`;
  `setOutlineColor:-1`, `setDensity:1`, `setCollision:1`; fixed 1, interactive 1, sleeping 0;
  keys (12, see header); `setShapeCount:1`, `setArtCount:0`.
* Statics are written by `setInnerRed/Green/Blue:` and `setShapeOpacity:` (so new shapes take
  the last edited colour); `setColor:` does not touch them.
* `setColor:` (unsigned 0xRRGGBB): `c = ccColorFromRGB`, inner* = `(unsigned)(c.x * 255.0f)`
  (fcvtzu), innerColor.rgb = c (alpha kept). `color` = `hexFromColor(innerColor)` with
  `(int)(x * 255.0f)` (fcvtzs) — float math; may round down (e.g. 61 → 60.999 → 60?): verify
  in Phase I, keep whatever the float math gives.
* `setInteractive:` only on change: post will_change, super, post changed,
  `setShapeCount:(i)`, `setArtCount:(!i)`.
* width = `ptmRatio * widthMeters`; `setWidth:` → `setWidthMeters:(w / ptm)` → updateRefRect.
* Inputs: density min 0.1 (0x3dcccccd) max 100; colour sliders 0..255 seg 254 (label COLOR
  only on red; colour labels "r","g","b"); opacity 0..100 seg 99 label nil, colour label "a";
  collision 1..6 seg 5.
* Circle: init size `ptm * 3.2f` (both), id 6001; DIAMETER slider `ptm*0.08f .. ptm*80`,
  seg 0; UI keys drop height/angle; refRect centred; `refBoundingBox` unrotated square;
  draws `drawDot(position, width*0.5f, innerColor)`.
* Rectangle: init `ptm*4.8f` x `ptm*1.6f`, id 6000; WIDTH/HEIGHT sliders `ptm*0.08f..ptm*80`.
* Triangle: init `ptm*3.2f` both, id 6002; WIDTH `ptm*0.08f..ptm*24`, HEIGHT
  `ptm*0.24f..ptm*72`; refRect `(-w/2, -h/3, w, h)`; vertices apex `2h/3`, base `-h/3`.
* Shape drawing (Rect/Triangle): `CGAffineTransformMakeRotation((double)(rot * -0.017453292f))`,
  corners computed in double from float half-sizes, each sum rounded to float, then added to
  the double position; fill innerColor, border 0 (border colour: read in Phase I).

  `Special::editorArtScale()` (= CSF / pixelsPerPoint). E3's "setScale(1/pixelsPerPoint)" rule

  `Localization::get`; `openwheels::iosBundlePath()` for `e_char_*` and `pe_objects-hd.plist`.

## Phase I notes (quirks kept)

* RefShape "last used colour" statics (61,136,199 / 100) updated by setInnerRed/Green/Blue
  and setShapeOpacity, not by setColor.
* Colour rounding: checked all 0..255 through `v * 0.003921569f * 255.0f` truncation — no
  value changes, so the `color` getter round-trips exactly (no quirk to reproduce).
* RefShape `setProperties` writes `_interactive` directly from `i` (no shape/art count update);
  copy/paste (`properties`) has no `i`, so pasted shapes become interactive.
* RefShape/DecorationRef notify KVO for `interactive` even when the value is unchanged.
* DecorationRef `setDecorationType` updates the shape count also when not interactive.
* DecorationRef: the iOS atlases have no `e_decoration_<n>.png` frames (only `e_1x1.png` among
  these), so on iOS the class could not work; the port logs (cocos2d-x) and continues with an
  empty refRect grown by 1 (`(-1,-1,2,2)`). The slider max for an empty dictionary is the
  64-bit `count - 1` (huge) and segments `0xFFFFFFFF`, as iOS.
* Triangle drawing reproduces the fused multiply-adds (`fmla`) of the iOS build with
  `std::fma`; Rectangle uses separate multiply/add (as its asm). Border width 0, border colour
  uninitialised on iOS → transparent here (no outline drawn either way).
* CharacterRef: `_charNode` is retained (ObjC strong ivar); only added to the stage when the
  ref has a grandparent (iOS messages nil otherwise). Anchor table has 11 entries; other ids
  log and use (0,0) (iOS reads past the table).
* Coordinator decisions applied: unknown KVC keys and extra `p<i>` → log + ignore;
  out-of-range character index → log, 0.
* `kvcUnsigned` of negative floats saturates to 0 (RE-TODO: NSNumber behaviour unverified).
* EditorSettings: `objectForKey(id)` = `[[levelItemRefClass alloc] init]` (autoreleased ref
  or nullptr; this is E3's `createRefForLevelItemID`). Factories cover every ref class incl.
  unregistered TokenRef/DecorationRef; `SignRef` (id 23) has no class → nullptr.
  `nameForLevelItem` / `sectionNames` return localized text.
